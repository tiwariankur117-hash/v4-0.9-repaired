06

Common questions

Does this create AI photos or MP4 videos yet?

No. Generators are frontend previews only.

Is my reference file uploaded?

No. The generator only displays its filename locally; the editor previews a locally selected video.

Can I export an edited MP4?

Not yet. The editor can download the unedited original clip, but rendering edits requires a later processing engine.

Is my login secure?

No. This is a browser demo; use temporary credentials only.
